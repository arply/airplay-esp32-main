Step 1

Measure

−60−40−200 dBFS

In stereo mode each run measures left, then right. Measure 3–5 positions around the listening spot, phone at ear height, microphone (bottom edge) towards the speaker.

Step 2

Target and range

Smoothing follows frequency: “Normal” uses 1/12 octave in the bass up to 150 Hz, getting coarser up to 1/3 octave from 3 kHz. “Fine” halves the windows, “Coarse” doubles them.

Cuts only: room-mode peaks are trimmed, dips are not filled. The iPhone microphone’s roll-off below about 80 Hz looks like a dip and is therefore ignored.

Optional

Bass enhancement

Psychoacoustic: bass below the cutoff that the speaker can’t reproduce is replaced by harmonics – your ear fills in the fundamental. Useful for small speakers, not with a subwoofer.

    Why doesn’t “Measure live” work here?
    
Inside the Claude app this page runs in a protected frame that blocks the microphone. Demo, import and listening still work. For live measuring, open the same file in Safari over HTTPS (e.g. GitHub Pages). Later arply serves it itself, and “Send to arply” posts the filters straight to /api/eq.

    
Import route: tap “Play sweep only” on one device, record with a second device (e.g. Voice Memos) and import the file here. The recording may start any time earlier.
